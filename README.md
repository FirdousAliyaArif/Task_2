Advanced Medical Data Preprocessing & Interpretable Diabetes Prediction Pipeline
Executive Overview & Project Description
This project delivers an end-to-end, clinical-grade machine learning solution engineered to predict diabetes onset using continuous physiological patient data. Developed on the benchmark Pima Indians Diabetes Dataset, the primary focus of this architecture extends beyond simple model performance to address real-world data quality constraints, robust feature engineering, statistical scaling, and medical-grade model interpretability.

Standard diagnostic datasets frequently suffer from implicit missingness disguised as invalid numerical values—such as zero readings in blood pressure, insulin, skin thickness, glucose, and body mass index (BMI). To mitigate severe bias caused by standard mean or median imputation, this pipeline implements Multivariate Imputation by Chained Equations (MICE) via Scikit-Learn’s IterativeImputer. By modeling each missing feature conditional on all other physiological variables while preserving explicit binary missingness indicators, the pipeline accurately reconstructs incomplete clinical profiles.

To maximize predictive sensitivity and handle extreme values without discarding critical boundary data, continuous features undergo percentile-based Winsorization (1st and 99th percentiles) followed by Quantile Transformation to achieve normal distributions across highly skewed attributes like Insulin and Diabetes Pedigree Function. Furthermore, domain-informed feature engineering was introduced, including a Glucose-BMI Interaction Term to capture synergistic metabolic risks and discrete Age Risk Stratification bins.

For binary classification, optimized tree-based ensembles and Logistic Regression baseline models were evaluated under Stratified K-Fold conditions using AU-ROC and AU-PRC metrics to preserve diagnostic class balance. Finally, to eliminate black-box opacity and ensure model safety in clinical decision-making, SHAP (SHapley Additive exPlanations) global bar plots and beeswarm feature importance diagrams were integrated. This confirms that elevated glucose concentration non-linearly drives positive diabetes log-odds, offering fully auditable decision transparency.
